# ARRJAVA FARMS — Official Luxury Project Presentation
> **A Farm Project by ABHISTA™**  
> *Residential Conversion Open Plots @ Begumpet Village | Near Patancheru, Mumbai Highway*

An award-winning, interactive, website-style scrolling project presentation designed for executive management, sales teams, channel partners, investors, and prospective farm villa buyers.

---

## 🌟 Presentation Features

1. **Cinematic Hero Experience**: Ambient background, logo reveal, gold typography, and presentation deck jump navigation.
2. **18 Storytelling Chapters**: Sourced strictly from verified project documents, brochure scans, and on-ground photography.
3. **Interactive Master Layout & Renders**: High-resolution zoom, pan, reset, and fullscreen inspection of architectural elevations.
4. **Official 3D Walkthrough Player**: Integrated 2-minute 3D walkthrough video with custom controls, fullscreen mode, and drone footage reels.
5. **Interactive Connectivity & Route Explorer**: Verified distances (1 KM Narasapur Hwy, 4 KM Aurobindo Sansa County, 5 Mins TRR Medical & Vignan School, 10 KM ORR, 14 KM Patancheru) and route maps.
6. **Real Site Experience Gallery**: Consecrated Lord Ganesha Temple, mature mango orchards, demarcation stones, under-construction cottages, and gazebo lounge.
7. **Development Milestones Timeline**: Transparent, honest progress tracking of completed and active site infrastructure.
8. **Presenter Deck Mode**: Bottom floating toolbar with keyboard slide navigation (`←` / `→`), slide notes for sales pitching, and fullscreen presentation toggle.
9. **Interactive Site Visit Scheduler & Directions**: Direct Google Maps GPS navigation with QR code scan and confetti booking celebration.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Custom Luxury Forest, Olive, Warm Sand & Gold Theme)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Audio Ambience**: Web Audio API Synthesized Nature Ambience

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```

---

## 🌐 Deployment to Vercel / GitHub

### Vercel Deployment (One-Click)
1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
